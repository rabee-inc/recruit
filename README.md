## 🔎 使い方
このリポジトリは以下の目的で活用いただけます。
1. **Rabeeを理解する**  
   カルチャーや働き方を鮮明にイメージできます。  
2. **候補者の疑問に答える**  
   deepwikiを使って質問することで、まるで社員と話しているように情報を得られます。  
3. **入社後のギャップをなくす**  
   具体的なキャリアパスや制度を事前に確認できます。
